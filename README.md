**Sacred Celestial Illumination Chair** is the owner's 2024 furniture design concept, presented as a **30 × 14 × 10.6 cm physical model**, made with acrylic, wood and white paint. Its original title, materials, dimensions and year are confirmed in the supplied Feng Ruixi A2.pdf (pages 58, 62–63). The owner explicitly records that the full-size chair was not completed (pages 67 and 69); earlier 1:10 prototypes and full-size joint studies are development work, not a fabricated full-size chair. The substantial four-part narrative covers the International Day of Light and church visits, the cross-shaped opening and Tadao Ando influence, material/proportion/joinery experiments, and directed-light/daylight photography (pages 6, 18, 35–59 and 62–69). The first of five separately supplied photographs is the cover; all five appear in order in the detail gallery with localized captions. The PDF itself and its page images are excluded from publication. No award is associated with this project.

## Editing

After editing local JavaScript or CSS, run `npm run version:assets` before checks. Both pages reference content-versioned assets so updated markup requests the matching resources. Checks reject outdated asset versions.

- `dist/index.html`: navigation, page sections, covers and work dialog.
- `dist/awards.html`: dedicated awards and honours page, including organiser information and a work link.
- `dist/portfolio.js`: owner-assigned category, internal provenance, cover and ordered image metadata.
- `dist/locales.js`: visitor content in five languages.
- `dist/app.js`: filters, language selection, navigation, dialogs and image gallery.
- `dist/style.css`: responsive visual system and gallery layout.
- `scripts/version-assets.mjs`: refreshes the asset versions in both HTML pages.

Work links use `#project/silver-wings`. Future works should be added only when supplied, with the category specified by the owner and matching copy in all five languages.
